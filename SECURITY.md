# Security Policy

## Reporting Vulnerabilities

The **Agentic Flow Studios** team takes the security and privacy of Miniscribe seriously. If you believe you have discovered a security vulnerability in Miniscribe, please report it to us responsibly.

### How to Report
Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please send an email to **security@agentic-flow.studio** or submit a private security advisory through the [GitHub Security Advisory interface](https://github.com/agentic-flow-studios/miniscribe.app/security/advisories/new).

Please include the following details in your report:
- Type of issue (e.g., IPC privilege escalation, buffer overflow, origin bypass, unsafe dependency)
- Step-by-step instructions or proof-of-concept script to reproduce the issue
- Affected operating system(s) and version of Miniscribe

### Response Timeline
- **Acknowledgement**: We aim to acknowledge receipt of security reports within 48 hours.
- **Assessment**: We will evaluate the report and provide an estimated resolution timeline.
- **Fix & Disclosure**: Once a fix is verified, a patch release will be issued alongside appropriate security advisory credit.
